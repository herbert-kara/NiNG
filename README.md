# NiNG

<div dir="rtl">

یک فورک مستقل از [PattNG](https://github.com/patterniha/PattNG) — که خودش از
[V2RayNG](https://github.com/2dust/v2rayNG) گرفته شده.

**اپ رسمی هیچ پروژه‌ای نیست.** هر سه پروژه نام و اپ خودشان را دارند، اما هیچ‌کدام
NiNG را تأیید نکرده‌اند یا پشتیبانی نمی‌کنند. اگر مشکلی دیدی، احتمالاً باید خودت
درستش کنی.

## ⚠️ Play Protect روی اپ اخطار می‌دهد

**این طبیعی است و به این معنی نیست که اپ بدافزار است.**

اپ با Play Store امضا نشده. کلید امضا یک کلید **خودساخته** است
(`CN=NiNG Release, O=herbert-kara`)، نه کلیدی که Google صادر کرده باشد. برای هر
اپی که بیرون از Play Store نصب می‌شود همین اتفاق می‌افتد — از جمله خودِ V2RayNG و
PattNG.

Play Protect دو نوع هشدار می‌دهد و فقط یکی‌شان قابل رفع است:

| هشدار | قابل رفع؟ |
| --- | --- |
| «اپ از توسعه‌دهندهٔ ناشناس است» | ❌ نه. بدون اکانت Google Play Developer قابل حذف نیست |
| «برنامه ممکن است مضر باشد» یا تاری | ✅ با گزارش‌دهی و نصب دوباره |

### اگر Play Protect جلوی نصب را گرفت

۱. **Play Protect → Settings (تنظیمات) → App verification (تأیید اپ) → Off (خاموش)**
   این تنها راه است. این تنظیم فقط برای نصب از خارج Play Store اثر دارد و روی
   اپ‌های فروشگاه اثری ندارد.
۲. اگر پیام «برنامه ممکن است مضر باشد» دیدی: **Install anyway → More details →
   Install anyway**.

### اگر Play Protect اپ را حذف کرد

۱. Play Protect → **History** → کنار اپ **⋮** → **Uninstall**. این فقط هشدار را
   پاک می‌کند و اپ را نمی‌بندد.
۲. اپ را دوباره نصب کن.

## مطمئن شو فایل سالم رسیده

هر release یک `SHA256SUMS.txt` دارد. بعد از دانلود، هش فایل را با آن مقایسه کن.

**ویندوز (PowerShell)**
```powershell
Get-FileHash .\NiNG_2.3.9-ning.30_arm64-v8a.apk -Algorithm SHA256
```

**لینوکس / مک / Termux**
```bash
sha256sum NiNG_2.3.9-ning.30_arm64-v8a.apk
```

اگر هش با خطی که اسم فایل در `SHA256SUMS.txt` دارد یکی بود، فایل سالم است. اگر یکی
نبود، **نصب نکن** و فایل را پاک کن.

## آپدیت داخل خود اپ

اپ می‌تواند نسخهٔ جدید را خودش پیدا کند. برای این کار باید نسخهٔ جدید با **همان
کلید امضا** ساخته شده باشد — که همیشه همین‌طور بوده. اگر روزی آپ آپدیت را پیدا
نکرد، یعنی یا از نسخه‌ای شروع کرده‌ای که با کلید دیگری امضا شده، یا نسخه هنوز
منتشر نشده است.

## چه چیزی نسبت به PattNG فرق دارد

این‌ها تغییرات این فورک است — بقیه از PattNG است:

- **برند NiNG** — نام، آیکون، رنگ
- **زبان فارسی** کامل، در کنار ۸ زبان دیگر
- **پرچم کشور** کنار هر کانکشن
  - **سریع:** از DNS — تقریبی است و ممکن است IP یک واسطه (Cloudflare یا CDN) را
    نشان بدهد، نه سرور اصلی
  - **دقیق:** دکمهٔ «اندازه‌گیری دقیق» روی همان ردیف — از خروجی واقعی همان
    کانکشن می‌پرسد و فقط همان ردیف را به‌روز می‌کند
- **نوار پایین** ساده: خط وضعیت + دکمهٔ Connect
- **آپدیتر** درون‌برنامه‌ای

## ساختن از سورس

Build محلی (Android SDK و NDK) پشتیبانی نمی‌شود؛ build فقط در CI انجام می‌شود.

```bash
git clone https://github.com/herbert-kara/NiNG.git
cd NiNG
git checkout my-releases
git submodule update --init --recursive
```

| فایل | کار |
| --- | --- |
| `.github/workflows/ci.yml` | کامپایل و تست |
| `.github/workflows/build.yml` | build، امضا، انتشار |
| `.github/workflows/upstream-sync.yml` | merge خودکار آپدیت‌های PattNG |
| `tools/verify_brand.py` | چک برند و guardهای ساختاری |
| `tools/verify_workflow_steps.py` | چک اینکه workflowها واقعاً قابل اجرا هستند |
| `tools/fork_manifest.txt` | فهرست ۳۷۵ فایلی که این فورک مالکشان است |

### چه اتفاقی می‌افتد وقتی PattNG آپدیت می‌دهد

روزی یک‌بار بررسی می‌شود. اگر چیز جدیدی باشد:

1. merge روی شاخهٔ جدا انجام می‌شود
2. **۳۷۵ فایل این فورک با نام بررسی می‌شوند** — اگر یکی حذف شده باشد، release
   ساخته نمی‌شود
3. تست‌های Gradle اجرا می‌شوند
4. اگر **conflict** پیش بیاید، کار **متوقف می‌شود** و فایل‌های درگیر را چاپ می‌کند.
   هیچ چیزی خودکار انتخاب نمی‌شود، چون انتخاب خودکار ممکن است فارسی یا برند را پاک
   کند
